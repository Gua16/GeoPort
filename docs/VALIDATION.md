# 变更与验证记录

基线为 Gua16/GeoPort 当前检出的 `main`，原始 HEAD：`d38c7c550512d3d1e0e6c49de59a695d417bc5f0`。源码的应用版本仍为 2.3.3，README 指向上游 4.0.2 发行版。没有上游二进制与源码一致性的证据，本次实现不声称包含二进制发行版全部功能。

## 变更记录

| 文件 | 变更 |
| --- | --- |
| `src/main.py` | 默认简洁入口、健康检查、健康就绪后打开浏览器、仅本机监听、关闭 Debug；配置接口和共享定位适配器；设备连接失败及隧道超时不再提示成功；隧道独立终止信号；地图在线数据后台加载并恢复 TLS 验证 |
| `src/settings.py` | 用户配置目录、输入验证、损坏提示、原子保存 |
| `src/location_math.py` | 坐标校验、基于固定基准的球面随机偏移 |
| `src/location_service.py` | 单会话串行定位、确认后更新状态、停止及断开释放连接、失败清除有效定位显示 |
| `src/templates/lite.html`、`src/static/lite.*` | 离线界面、显式保存、半径恢复、连接控制、状态与失败信息 |
| `src/templates/map.html` | 保留原地图，添加返回简洁模式和保存基准；共用定位服务并显示失败；连接状态恢复 |
| `requirements.txt`、`requirements.lock` | 固定兼容依赖与安装哈希；Windows 额外声明 pywin32 |
| `tests/` | 数学、配置、定位会话、HTTP、启动及可选浏览器验收 |

pymobiledevice3 的源码没有修改。该版本源码需要旧的 `cli_install_wetest_drivers` 及 `get_mobdev2_lockdowns` 接口，经检查使用 4.4.0；`ipsw-parser` 固定为 1.3.8，以保留旧的 `ipsw_parser.img4` 模块。

## 当前验证结果

- Python 3.12.14、Debian 13、x86_64；带哈希依赖安装及兼容性检查通过。
- 25 项自动化测试通过。包括 4 组各 1,000 次随机点计算（普通坐标、接近极点、南北极及日期变更线），所有点距离均在 300 米内，基准不变，面积分布抽样符合预期。
- 临时配置目录读写、重新加载、损坏文件保护、原子替换失败保护、无效经纬度/半径验证通过。
- 模拟设备回归通过：一次操作一次设置、多次设置保留单会话、重复设置/停止/连接并发拒绝、停止实际清除、未应用坐标的重新连接设备仍执行清除、失败不误报成功。
- iOS 16 与 iOS 17+ 的原始 DVT/RSD 适配路径使用模拟传输验证；这是自动化回归，**不是实体设备连接结果**。
- Chromium 的 390 像素移动视口验收通过：保存、半径恢复、两次单次偏移、恢复基准、停止、断开、真实进程重启后配置恢复且不自动应用、设备失败显示；拦截全部非本地请求后，无外部资源请求、JavaScript 错误或横向溢出。
- 简洁界面与渲染后的地图内联 JavaScript 语法检查通过。默认首页、静态资源及健康检查未调用外部网络或设备扫描。

## 启动耗时

在同一云机各启动 3 个新进程；开启自动浏览器路径，但使用本地 `/usr/bin/true` 代替实际浏览器窗口，避免浏览器加载干扰。时间从启动进程至首次首页 HTML 返回，包含 Python 导入和 Flask 启动。原版首页使用当前云机网络状态，油价不可达，其余可访问在线请求仍可能影响耗时。

| 测量 | 原版 | 简洁版 |
| --- | ---: | ---: |
| 首次新进程（非真正冷缓存） | 4.403 s | 0.556 s |
| 后续第 1 次 | 3.619 s | 0.575 s |
| 后续第 2 次 | 3.689 s | 0.627 s |
| 后续两次平均 | 3.654 s | 0.601 s |

简洁版首页自身响应为 5–6 ms，启动已去除固定 2 秒等待。数据不包含浏览器绘制、设备扫描或 iPhone 连接时间；没有清空系统缓存或重启机器，真正冷启动与目标用户机器性能尚未验证。

## 尚未完成的实机验收

当前云机没有 USB 总线、usbmuxd 服务或 iPhone。因此实际扫描返回设备错误，实机定位、设备拔出后的传输行为、连续随机偏移、停止后的 iPhone 实际位置、首次配对、开发者模式、旧 iOS 的开发者镜像及 Windows/macOS 驱动和权限流程均未验证。

执行实机验收时，使用用户原先能正常工作的系统、iOS 版本及配对记录，依次验证：原地图设置/停止、简洁模式基准设置、连续偏移后与基准距离、恢复基准、停止、拔出设备后的失败提示、重启后不自动应用，以及断网条件下已配对设备的定位。没有实机结果前，不承诺所有 iOS 版本兼容。

地图瓦片、在线搜索、路线服务与油价依赖互联网。当前网络策略仍阻止油价域名，因此油价功能未通过；简洁模式不依赖这些服务。没有制作或验证各平台二进制安装包，交付方式是上述可运行源码与 Python 启动命令。
