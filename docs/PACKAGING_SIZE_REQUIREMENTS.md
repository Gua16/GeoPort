# APP 体积优化需求

2026-10-12 Codex。状态：已按用户后续授权实施。0.1.4 完成云端与原生打包验证，待用户实机回归。以下现状为 0.1.3 的历史基线。

## 需求

减小 macOS APP 体积。评估沿用原版 PyInstaller 单文件压缩方式，并精简不需要的模块与资源。保留现有功能、系统管理员授权、用户配置、离线简洁页面与设备连接能力。

## 已验证的现状

本机原版 `GeoPort-mac.app` 为 51.45 MB。原版压缩归档含 `pycountry`、`jedi` 和 PIL，归档内容展开约 106.7 MB。新版 `GeoPort Lite.app` 0.1.3 (4) 为 126.66 MB；0.1.2 为 126.65 MB，新功能仅增加约 0.01 MB。数字为文件逻辑大小，排除符号链接重复计数。

当前 `packaging/macos/GeoPortLite.spec` 使用展开式 APP，并对 `pymobiledevice3`、`pycountry` 调用 `collect_all`。体积差异主要来自压缩与展开形式、依赖收集范围；不能仅根据目录存在就判定某依赖可以删除。

## 后续验收

- 比较 APP 与 DMG 大小，记录优化前后值；具体目标体积尚未确定。
- 验证单文件解压后的管理员授权、后台启动、资源路径和重复启动行为。
- 通过回归测试和 iPhone 实机连接、设置坐标、随机偏移、停止、退出与历史持久化测试。
- 不修改系统安全设置，不要求用户额外安装 Python 或依赖。

## 0.1.4 验证结果

使用 GitHub 原生 Apple Silicon macOS 15 runner、Python 3.12、相同锁定依赖比较。MB 为十进制逻辑字节，排除符号链接重复计数。

| 方案 | APP | DMG | 两次无浏览器启动 |
| --- | ---: | ---: | --- |
| 宽泛收集对照 | 137.48 MB | 91.38 MB | 0.818 / 0.800 秒 |
| 精简单文件候选 | 35.05 MB | 35.09 MB | 1.000 / 36.680 秒 |
| 最终精简展开式（自适应图标） | 69.76 MB | 40.63 MB | 0.544 / 0.607 秒 |

最终 APP 比对照减少约 49%，DMG 减少约 56%。最终图标采用 Xcode 26.3 Icon Composer；对照/单文件候选使用此前图标目录，因此数值含少量图标资源差异。测量原始 JSON 见 `docs/design/packaging/`。

未选择单文件：重复启动耗时波动明显，而且 PyInstaller 已提示单文件 `.app` 与 macOS 安全机制的兼容性限制。保留展开式、移除不用的设备 CLI、自动补全、图像依赖和国家翻译，保留设备服务与必需元数据。图标在 Contents/Resources 中仅放一份编译目录与每种 ICNS。
