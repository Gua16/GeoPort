# GeoPort 页面与服务退出需求

2026-10-12 Codex。状态：完成。0.1.3 已实现，按钮退出与关页延时退出已实测。

## 已提出的需求

点击“退出 GeoPort”后，停止模拟、关闭设备会话与隧道、恢复 remoted、退出 GeoPort 服务，并自动关闭当前 GeoPort 页面。不关闭浏览器或其他标签页，不删除已保存的基准与半径。停止或清理失败时保留页面并显示失败原因。

## 当前行为（已验证）

`src/static/lite.js` 等待 `/exit` 成功后调用页面关闭；地图页面使用相同的确认顺序。`src/main.py` 的公共退出流程先清理设备与隧道，再退出服务。Safari 默认打开的页面已经验证：模拟中点击退出，服务与当前标签页关闭，其他标签页保留；用户确认手机恢复实际位置。

## 浏览器约束（已验证规范，未实测）

`window.close()` 受浏览器限制。HTML 规范允许关闭由网页创建的窗口，或只有一条会话历史记录的顶层页面；不能保证所有 Safari/Chrome 标签页均可关闭。参考 [HTML Standard 的 close 规则](https://html.spec.whatwg.org/multipage/nav-history-apis.html#dom-window-close)。

浏览器拒绝关闭时保留“服务已退出，请关闭此页面”提示。不改变浏览器安全设置。默认 Safari 打开方式已实测；其他浏览器和有导航历史的标签页仍需验证。

## 关闭页面后延时退出

本次实现采用 120 秒延时。页面通过 SSE 长连接保持在线，服务端统计连接；最后一个连接断开后倒计时，期间重新打开页面则取消退出。选择 SSE 是因为现有 Flask 可直接支持，无需新增依赖。前端不使用后台定时心跳；切换标签不关闭连接。简洁与地图页面均接入；未打开任何界面的命令行服务不自动倒计时。

要求：仍有任一 GeoPort 页面打开时不退出；刷新、切换标签和页面暂时进入后台不应误退出；浏览器崩溃、后台冻结、Mac 睡眠与唤醒需验证。倒计时到期采用与按钮相同的停止模拟及资源清理流程，保留用户配置。

55 项回归测试覆盖多个页面、120 秒上限、刷新重开取消、重复关闭与清理失败重试。Mac 睡眠唤醒、浏览器冻结和崩溃仍需独立验证。
