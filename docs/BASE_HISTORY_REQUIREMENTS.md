# 基准坐标历史需求

2026-10-12 Codex。状态：完成。0.1.3 已实现并验证存储与界面选择。

## 用户需求

基准坐标记录最近的 5 条。

## 已确认规则

- 仅成功保存基准坐标时更新历史，最新在前，最多保留 5 条。
- 相同坐标去重；再次保存时移到最前，不占用额外记录。
- 随机偏移产生的坐标不计入基准历史。
- 历史保存在本机，退出与重启后保留。

2026-10-12 用户已确认这些规则。简洁页面使用系统下拉框展示历史；选择只填入输入框，点击“保存基准”后更新基准和历史，不自动设置 iPhone。

验证：53 项回归测试包含上限、去重、重启保存、写入失败与随机偏移不新增历史。安装版保存 7 条后保留最近 5 条，重复保存移到最前；界面选择及保存通过，退出重启后历史保留。旧配置中的现有基准自动成为第一条历史。
